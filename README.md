# Open-Deck
![icon](https://github.com/kawa-nobu/Open-Deck/assets/44832116/3d4d1e64-6a74-4587-a248-da8424190d41)  


## 機能
* ポストフォームのポップアップ表示 (サイドバーの投稿ボタンで開閉、投稿後に自動で閉じる)
* タイムラインカラム
* 通知カラム
* Explore(ユニバーサルカラム※1)
* カラム管理ダイアログ (サイドバーのカラム管理ボタンで開く。タイムライン / 通知 / Explore / リストのカラムをまとめて追加し、X のリスト一覧から選んだリストも含めて、既存カラムの並べ替え・ラック間の移動・閉じるを一覧で編集して一括で適用)
* 端末スペックやブラウザが許す限り制限なくカラムを追加可能
* サイドラック (任意のカラムを画面の左または右に固定表示。カラムの追加先と並びはカラム管理ダイアログでメインラック / サイドラックから選び、位置は全体設定で左右を選択。カラムが無いあいだは表示されない)
* 1秒単位で設定できるカラムの自動更新(タイムライン・検索対応)
* 自動更新後の先頭保持 (更新前に一番上だったカラムは、新着が上に挿入されても一番上に保って新着を見せる。全体設定でオン / オフを切り替え、既定はオン)
* 見えていないタブでの自動更新の停止 (Open-Deck のタブが別タブの裏・最小化などで隠れているあいだは全カラムの自動更新を止め、表示に戻ったとき最後の更新から設定した間隔以上経ったカラムだけを 1 回すぐ更新する。判定はブラウザの可視状態 (Page Visibility API) に従うため、非アクティブでも画面に見えているウィンドウや一部が重なっているだけのウィンドウでは更新を続ける。別のウィンドウに完全に覆われたウィンドウで止まるかはブラウザと OS の実装に依存し、Windows 版 Chrome では止まる)
* 1rem(単位)で自由に調整できるカラム幅設定機能
* 表示サイズ設定 (文字サイズ / UI サイズ / カラム内容のサイズを % で別々に設定。デッキのタブではブラウザ標準ズーム (Ctrl +/-) を無効化し、この設定で拡大縮小する。ズーム無効化は Chromium 系ブラウザのみで、Firefox では効かない。100% はブラウザ既定倍率での表示。カラム内容のサイズは Chrome 128 以降で動作し、Firefox (126 以降で CSS zoom を実装) では未検証)
* 無制限のプロファイル(カラム構成・設定)保存・切り替え機能

※1 トレンドや検索以外にDM画面やリストなどを自由に設定可能なユニバーサルなカラムです。  

**FireFox ESR115(ESR版ベース含む)をお使いの方はツイート種類の表示モードは動作しません。  
これはESR版が本拡張機能が使用しているCSSのセレクタに対応していないためです。**

## 導入方法(推奨)
### Chrome Web Store経由
[Chrome Web Storeのリンク](https://chromewebstore.google.com/detail/open-deck/gmkadaeibmhchpimnfplodelecmogdic) へアクセスし、  
[Chrome(Brave等)に追加]ボタン押下で簡単にお使いの端末へ導入が完了します。

### Mozilla公式サイト経由

[addons.mozilla.org(AMO)](https://addons.mozilla.org/ja/firefox/addon/open-deck/) へアクセスし、  
[FireFoxへ追加]ボタン押下で簡単にお使いの端末へ導入が完了します。

## 導入方法(デベロッパーモード)
**導入方法が分かる人のみお使いください。**
* お好みのブラウザ版ブランチのzipを落とす 
* デベロッパーモードで導入する
* 拡張機能実行用のURL https://twitter.com/run-opdeck を開く

## バージョンの付け方
このリポジトリは [kawa-nobu/Open-Deck](https://github.com/kawa-nobu/Open-Deck) (以下 upstream) のフォークですが、バージョンは upstream と別に、セマンティックバージョニング (`MAJOR.MINOR.PATCH`) で付けます。

* 拡張の動作を変える PR では、`manifest.json` と `manifest_firefox.json` の `version` を同じ値に上げる
* 不具合修正は PATCH、機能追加は MINOR を上げる。後方互換のない変更 (機能の削除、保存済みの設定が使えなくなる変更など) は MAJOR を上げる
* upstream の変更を取り込むときも `version` はこのリポジトリの値のままにし、取り込んだ内容に応じて上げる
* 既に使っている環境で `version` が変わると、次回起動時に更新の確認ダイアログが出る。OK を押すと、このリポジトリのマージ済み PR 一覧を開く
